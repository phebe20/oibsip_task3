# Amazon Products Review — Data Cleaning

## Project Overview

This project focuses on cleaning an Amazon product reviews dataset using Python. The dataset contained several data quality issues that needed to be checked and handled before the data could be used for further analysis.

The main goal was to make the dataset more organised and reliable while keeping track of the cleaning decisions made along the way.

## Objectives

- Inspect the dataset and identify data quality issues.
- Check for missing values, duplicate records, and completely blank rows.
- Review data types and identify inconsistent values.
- Clean and standardise columns such as product prices, discounts, ratings, and rating counts.
- Document the cleaning steps and explain the decisions made.

## Tools Used

- Python
- Pandas
- NumPy
- Jupyter Notebook

## What I Did

I began by examining the original dataset to understand its structure and identify the issues that needed attention. I checked the missing values, duplicate records, blank rows, and data types across the columns.

I then worked through the cleaning process, handling missing and duplicate records and checking inconsistent values in the product information. I also examined price, discount, rating, and rating-count columns to identify formatting issues and values that needed further attention.

Throughout the process, I compared the dataset before and after cleaning to help assess the changes made.

## Key Takeaways

This project helped me understand that data cleaning involves more than removing missing values and duplicates. It also requires checking whether values are consistent, identifying unusual entries, and making sensible decisions about how to handle different data quality problems.

Documenting these decisions was an important part of the process because it made the cleaning steps easier to follow and review.
